How these numbers are calculated
  • Active = still in progress: available to NGOs (not expired) or claimed and awaiting pickup.
  • Completed = an NGO marked the pickup as done. Expired = nobody claimed it before its deadline. Withdrawn = the donor removed it while unclaimed.
  • Every donation is counted in exactly one outcome, so the outcomes always add up to the total.
FoodShare does not estimate kilograms or meals saved: quantities are entered as free text (for example "20 meals"), so there is no reliable number to add up.
