Quick start (curl)

Log in once with a cookie jar, then reuse it.

B=http://127.0.0.1:5000/api/v1
# 1. get a CSRF token (starts the session cookie jar)
T=$(curl -s -c jar $B/csrf | jq -r .data.csrf_token)
# 2. log in (this rotates the session: use the NEW token it returns)
T=$(curl -s -b jar -c jar -H "X-CSRFToken: $T" -H "Content-Type: application/json" \
  -d '{"email":"ngo1@demo.local","password":"demo1234"}' $B/auth/login | jq -r .data.csrf_token)
# 3. read freely; send the token on every POST/DELETE
curl -s -b jar "$B/listings?radius=25"
curl -s -b jar -X POST -H "X-CSRFToken: $T" $B/listings/1/claim

Requests without a valid X-CSRFToken get 403 csrf_failed.
